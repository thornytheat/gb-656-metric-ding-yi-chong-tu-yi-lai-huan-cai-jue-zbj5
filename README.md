# metricgraph 指标定义冲突与依赖环裁决

分析治理组在指标发布前导入定义，系统生成表达式稳定签名，识别同名冲突、依赖环、缺依赖与版本区间重叠。

## 模块

- 定义采信：字段演进、空定义与坏行隔离。
- 表达式归一：别名、空白与交换项生成稳定签名。
- 冲突判定：同名同版本多定义按优先级裁决。
- 依赖拓扑：依赖环、自引用与缺边检查。
- 影响清单：定义变化的反向影响范围。
- 版本裁决：半开生效区间与陈旧提交拒绝。
- 指标目录：单一目录 CSV。
- 指标依赖裁决：批次绑定输入版本、修订留旧版、中断续跑、匿名链路与授权审计。

## 启动

```bash
docker compose up --build
```

浏览器打开 <http://localhost:18215/>。

## 测试

```bash
docker compose exec -T app pytest -q
```

核心反例包括：交换项顺序不同、同名公式冲突、三节点依赖环、生效区间重叠和陈旧版本提交。

指标依赖裁决另有两条：修改指标定义后旧裁决不得被覆盖（新裁决 + 旧版留档），
以及裁决写入中断后同输入重试必须从检查点续跑而不是新增一条结果。
